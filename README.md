# IRONFORGE Gym Website

A modern, responsive single-page website for a fictional premium gym called IRONFORGE.

## Features
- Fully responsive design (mobile-first)
- Smooth scrolling navigation
- Hero section with call-to-action
- Services, Trainers, Membership plans with pricing cards
- Contact form (demo)
- Dark, energetic fitness theme

## Tech Stack
- HTML5
- CSS3 (with Flexbox/Grid)
- Vanilla JavaScript
- Font Awesome icons
- Google Fonts

## Getting Started
1. Clone the repo
2. Open `index.html` in your browser
3. Customize images, content, and colors as needed
